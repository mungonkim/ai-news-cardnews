# 이미지 프롬프트 체계 (자동 생성용)

이미지 프롬프트는 두 층으로 만든다.
1. **고정 규칙**: 매번 똑같이 붙는다 (품질, 구도, 금지 사항)
2. **가변 장면**: 기사마다 Claude가 새로 쓴다

최종 프롬프트 = `[가변 장면]` + `[고정 규칙]`

---

## 1. 장면 작성 지시문 (Claude에게 주는 프롬프트)

```text
너는 인스타그램 AI 뉴스 카드뉴스의 이미지 디렉터야.
아래 기사 내용으로 카드에 들어갈 이미지의 "장면"만 작성해 줘.

[기사 핵심]
{기사 제목, 핵심 변화 한 줄, 일반인에게 의미}

[만들 이미지]
- 표지 1장, 중간 장 {개수}장 (대상 장: {장 번호와 장 제목})

[장면 작성 원칙]
1. 주인공은 하나. 소재를 여러 개 흩어 놓지 말 것.
2. 기사의 핵심 변화가 한눈에 보이는 "순간"을 그릴 것 (누가 무엇을 하는 중인지).
3. 추상적인 설명 말고 구체적인 사물과 행동으로 쓸 것.
4. 장마다 소재와 구도를 다르게 하되, 한 기사 안에서는 하나의 이야기로 이어지게 할 것.
5. 표지는 가장 눈에 띄는 장면, 중간 장은 설명을 돕는 장면으로 쓸 것.
6. 화면 속 글자가 필요하면 한글 한두 단어만 허용하고, 나머지는 흐릿한 줄이나 도형으로 표현할 것.
7. 기사에 나오는 실존 인물, 브랜드 로고, 유명 캐릭터는 써도 된다 (기사 주제와 관련될 때만). 단, 생성 서비스가 거부하거나 닮지 않게 나오면 실제 사진으로 대체하고 출처를 적는다.

[출력 형식]
장 번호별로 "장면: ..." 한 문단과 "촬영: ..." 한 줄(카메라, 렌즈, 조명, 분위기)을 써 줘.
```

## 2. 고정 규칙 (모든 이미지에 자동으로 붙는 문구)

### 공통
```text
넣지 말 것: 읽을 수 있는 긴 글자와 숫자, 워터마크, 만화 같은 어색한 3D 장난감 느낌.
결과는 선명하고 자연스러운 질감의 고품질 이미지여야 한다.
```

### 표지용 (세로 3:4, 1080x1440)
```text
세로 3:4 비율(1080x1440)의 카드뉴스 표지용 이미지.
핵심 요소는 위쪽 60% 안에 두고, 아래쪽 40%는 단순하게 비워 둘 것 (제목 글자가 올라갈 자리).
좌우 가장자리 약 40px는 비워 둘 것.
```

### 중간 장용 (가로로 긴 이미지, 약 1.6:1)
```text
가로로 긴 비율의 이미지 (약 1.6:1, 예: 1800x1100).
핵심 요소는 가운데에 두고, 가장자리가 잘려도 이야기가 이어지게 할 것.
```

## 3. 최종 프롬프트 조립 예시 (이번 ChatGPT 기사)
```text
{가변 장면} 노트북 화면에 AI 챗봇 대화창이 열려 있다. 왼쪽은 글로만 된 답, 오른쪽은 같은 답이 눌러 볼 수 있는 계산기로 바뀌어 있고, 손가락이 슬라이더를 누르려는 순간.
{촬영} 낮은 각도 접사, 얕은 심도, 부드러운 스튜디오 조명, 고급 광고 사진 느낌.
{고정: 중간 장용} 가로로 긴 비율의 이미지 (약 1.6:1) ...
{고정: 공통} 넣지 말 것: ...
```

---

## 4. 규칙 개선 방법
- 만든 이미지가 마음에 안 들면, 이유를 **고정 규칙**에 한 줄 추가한다 (모든 기사에 반영됨).
- 특정 기사에서만 필요한 보정은 가변 장면에만 적용한다.
- 이미지를 만드는 서비스에 따라 문구가 다르게 해석될 수 있으니, 서비스를 바꿀 때는 같은 장면으로 한 번 비교해 본다.
